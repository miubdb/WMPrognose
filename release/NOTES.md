## JANIQUIZITION für Windows

**Download: `JANIQUIZITION-Windows.zip`** (unten unter „Assets“)

1. ZIP herunterladen → Rechtsklick → **Alle extrahieren …**
2. **`JANIQUIZITION-STARTEN.bat`** doppelklicken (Windows-Warnung: „Weitere Informationen → Trotzdem ausführen“; Firewall: „Private Netzwerke“ erlauben)
3. Im Browser **eigenes Admin-Passwort** festlegen
4. Showmaster-Pult öffnen, eines der **zwei Pakete** wählen, Spielraum erstellen – fertig

Nichts muss installiert werden (Laufzeit ist enthalten). Update: neue ZIP in denselben Ordner entpacken, `data` bleibt erhalten.
