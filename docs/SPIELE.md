# Welche Spiele funktionieren?

Alle Spiele unten sind fertig, automatisch getestet und im Browser mit mehreren Handys geprüft. (Dieselbe Liste steht im Admin unter **Start → Diese Spiele funktionieren**.)

| Spiel | So geht’s | Punkte |
|---|---|---|
| 🧭 **WO ZUR HÖLLE?** | Pin auf der Karte setzen – je näher, desto mehr Punkte (60 s) | bis 250 |
| 😈 **LÜGEN HABEN KURZE BEINE** (neu) | Alle erfinden eine falsche Antwort (45 s), dann wird die echte gesucht (30 s). Gleiche Lügen werden zusammengefasst, die eigene Lüge ist nicht wählbar | 200 fürs Erkennen + 100 je Hereingefallenem |
| ↔️ **SCHÄTZKORRIDOR** (neu) | Einen Zahlenbereich angeben, in dem die Lösung liegt – je enger, desto mehr Punkte, daneben = 0 | bis 300 |
| 🔄 **VERDREHTE WELT** (neu) | Ein ins Gegenteil verdrehter Filmtitel – das Original tippen, je schneller desto mehr Punkte | 150–300 |
| 🧲 **MATCHMAKER** | Sechs Paare verbinden (60 s) | 50 je Paar, max. 300 |
| ↕️ **SORTIER’S!** | Fünf Karten in die richtige Reihenfolge bringen | 50 je richtigem Platz |
| ✨ **EINZIGARTIG** | Eine gültige Antwort nennen, die kein anderer nennt; der Showmaster kann jede Antwort korrigieren | 300, doppelt = 0 |
| 👁️ **GLITCH** | Bild merken, dann die veränderte Stelle antippen | bis 250 |
| 🎯 **SETZ AUF MICH** | Zahl schätzen, dann bis zu 50 % der eigenen Punkte auf einen Tipp setzen | Rang + Einsatz |
| 🔗 **DIE VERBINDUNG** | Vier Hinweise – je früher richtig, desto mehr Punkte | 300 / 225 / 150 / 75 |

**Finale (eines davon pro Paket):**

| Finale | So geht’s | Punkte |
|---|---|---|
| 🤝 **KICKBASE-KONSENS** (Hauptshow) | Fünf Fragen, geheim eine Person wählen (auch sich selbst oder Michael); die meistgewählte Person bringt den Tippern Punkte, mind. 2 Stimmen | 5 × 100, max. 500 |
| 🔒 **FINAL LOCK** | Vier Abschlussaufgaben, Rangliste verborgen | bis 1.450 |

Dazu gehören: Proberunde je Spiel (ohne Punkte), Marktwert-Update nach jeder Runde, Siegerehrung, Pause und Wiederverbinden.

**Nicht mehr aktiv:** CODEBREAK (Rätsel mit Hinweisen) und der klassische Modus mit Kategorienwand – laufen technisch weiter, sind aber nicht Teil des Spieleabends.

## Zum Ausprobieren: Paket „Neue Spiele – Testlabor“
Enthält die drei neuen Spiele mit Beispielfragen und dem KICKBASE-KONSENS als Finale. Nach dem Update im Admin (Start → „Jetzt sicher aktualisieren“) im Showmaster-Pult wählbar. Eigene Fragen legst du im Admin unter **Fragen → ＋ Neue Frage** an (mit „Testen“-Knopf).

## Ideen, die noch nicht gebaut sind
| Idee | Was fehlt |
|---|---|
| PIXELPANIK (verpixeltes Bild wird schärfer) | Bilddateien, die offline mitgeliefert werden |
| TONSPUR (Geräusche erkennen) | Audiodateien, offline |
| DUELL DER DEPPEN (zwei duellieren sich, andere wetten) | Festlegung, welches Duell gespielt wird |
| DIE ARENA (inszenierte Duellrunde) | Spielprinzip noch offen |
| ZEITSPRUNG (Ereignisse auf einer Zeitachse) | geht schon als SORTIER’S!-Frage mit Jahreszahlen; eigener Modus optional |
| PANIK / HOT WIRE (unter Zeitdruck reagieren) | Spielidee konkretisieren |
