# Spiele in JANIQUIZITION

17 reguläre Spiele + 2 Finals. Alle fertig, automatisch getestet und im Browser mit 2 und 7 Spielern geprüft. (Dieselbe Liste: Admin → Start.)

| Spiel | So geht’s | Punkte |
|---|---|---|
| 🧭 **WO ZUR HÖLLE?** | Pin auf der Karte setzen | bis 250 |
| 🧲 **MATCHMAKER** | Sechs Paare verbinden | 50 je Paar |
| ↕️ **SORTIER’S!** | Fünf Karten sortieren | 50 je Platz |
| ✨ **EINZIGARTIG** | Antwort, die kein anderer nennt (Showmaster kann jede Antwort korrigieren) | 300 |
| 👁️ **GLITCH** | Veränderung im Bild antippen | bis 250 |
| 🎯 **SETZ AUF MICH** | Schätzen, dann bis 50 % der Punkte wetten | Rang + Einsatz |
| 🔗 **DIE VERBINDUNG** | Vier Hinweise, früh richtig = mehr | 300–75 |
| 😈 **LÜGEN HABEN KURZE BEINE** | Falsche Antworten erfinden, die echte finden | 200 + 100 je Getäuschtem |
| ↔️ **SCHÄTZKORRIDOR** | Zahlenbereich eingrenzen | bis 300 |
| 🔄 **VERDREHTE WELT** | Verdrehten Filmtitel erraten | 150–300 |
| 🟪 **PIXELPANIK** | Pixelbild wird schärfer (5 Stufen à 6 s) | 300 / 240 / 180 / 120 / 60 |
| ⚔️ **DUELL DER DEPPEN** | Zwei duellieren sich (3 Fragen), andere tippen auf den Sieger; Duellanten rotieren fair | Sieg 250 · Tipp 100 · Remis 75 |
| 🏟️ **DIE ARENA** | 3 Fragen für alle, Falsche scheiden aus | 3 × 50 + 150 Bonus |
| 🎧 **TONSPUR** | Geräusch erkennen (1. Hören, 2. Hören, Hinweis) | 300 / 200 / 100 |
| ⏳ **ZEITSPRUNG** | Ereignis zwischen vier Anker-Ereignisse einordnen | 250 (Nachbarfeld 100) |
| 🚨 **PANIK** | Teamspiel: verteilte Hinweise → Code; Entschärfer rotiert | 200 für alle (+50 schnell) |
| 🕵️ **HOCHSTAPLER** | Alle kennen das Wort bis auf einen; Hinweise, Abstimmung | 300 unentdeckt · 100 erkannt |

**Finals:** 🤝 KICKBASE-KONSENS (5 × 100) · 🔒 FINAL LOCK.

**Testpakete:** „Neue Spiele – Testlabor“ (3 Spiele) und „Neue Spielmodi – Testpaket“ (die 7 neuesten, je 3 Aufgaben). Nach dem Update im Admin unter *Start → Jetzt sicher aktualisieren*.

**Medien:** Bilder (Emoji, Apache-2.0) und Töne (selbst synthetisiert) sind lizenzfrei und offline. Eigene Bilder/Töne im Admin hochladen – nur, was ihr nutzen dürft.

**Nicht mehr aktiv:** CODEBREAK, klassischer Modus mit Kategorienwand.
